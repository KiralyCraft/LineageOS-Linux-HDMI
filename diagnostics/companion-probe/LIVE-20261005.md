# Live companion compatibility probe, 2026-10-05

The query-only probe passed live loading, ioctl checks, and unloading. The user
authorized a standalone `insmod` test to avoid rebooting after Magisk installation.
The Magisk ZIP was staged but was not installed.

This validates the initial compatibility gate. The functional timing guard and
asynchronous Xorg TearFree backend have not been implemented or deployed by this
probe. No timing session or vblank reference was created.

## Live verification

Standalone loading used Android's existing namespace and `toybox insmod`, then
the Android query tool validated the exact release and build identity. It
reported ABI 1 and import mask `134217727` (all 27 bits). Wrong size, ABI,
reserved fields, input features, unknown ioctl, and null pointer checks passed,
as did 100 repeated queries. The query tool closed its descriptor.

Normal `toybox rmmod hdmi_companion_probe` succeeded afterward. The module was
absent from sysfs after cleanup. Kernel taint stayed `12804`, and SELinux,
signature/version checking, and CFI settings were not changed. Xorg PID 1144
retained its original process start time. The existing HDMI launcher/runtime
and Android graphics drivers were not replaced.
